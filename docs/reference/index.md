# Package index

## All functions

- [`coord_zoomFeature()`](coord_zoomFeature.md) : Zoom into given
  feature

- [`formatPc6()`](formatPc6.md) : Format an string or vec of strings as
  PC6.

- [`geom_rectFeature()`](geom_rectFeature.md) :

  ggplot annotation that draws an rect around a given spacial feature.
  Combine with
  [`coord_zoomFeature()`](../reference/coord_zoomFeature.md) for pretty
  insetting.

- [`loadElapse()`](loadElapse.md) : Loads ELAPSE from the given path or
  from extdata.

- [`pollutionFromBag()`](pollutionFromBag.md) : Get air pollution data
  for a postcode with BAG database.

- [`pollutionFromPc6()`](pollutionFromPc6.md) : Get air pollution data
  for a postcode with Postcode6 database.

- [`postcodElapse()`](postcodElapse.md) : Get the air pollution data for
  a given postcode.
